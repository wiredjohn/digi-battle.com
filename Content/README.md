# /Content

This directory does not contain resources served by the site. 

This directory structure and it's files has been recreated here from the old version of Digi-Battle.com to preserve image paths indexed by search engines, and to not break references to images used by other websites. 

Images used by the site can be found in the [assets](https://github.com/wiredjohn/digi-battle.com/tree/main/assets) directory. Card scans can be found in [assets/img/upper-deck-cards](https://github.com/wiredjohn/digi-battle.com/tree/main/assets/img/upper-deck-cards).
