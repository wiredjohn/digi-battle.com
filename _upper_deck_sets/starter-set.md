The Digimon Starter Set was released in February 2000 as part of the initial release of the Digi-Battle card game, [according to Wikipedia](https://en.wikipedia.org/wiki/Digi-Battle). The Starter Deck included enough cards for 2 players to build a deck each and play the game. As well as the trading cards, the deck box included a playmat, a rule book and deck lists for 2 players.

The set is available in both 1st Edition and Unlimited Edition.
