This is one of the most scarcely documented things about the Digi-Battle card game. I still don't know with certainty what cards were released and how they were released, but I have been able to gather some information here.

Inside booster packs there was a chance of finding a rare holographic variant of one of the Starter Set cards. Through the power of Wayback Machine I have found what cards were released in some of the boxes:

 - [Booster Set 1](https://web.archive.org/web/20001102102541/http://www.upperdeck.com/digimon/00entdbst1.html)
 - [Booster Set 2 Wave 2 (YELLOW)](https://web.archive.org/web/20001102112039/http://www.upperdeck.com/digimon/00entdbst2w2.html)
 - [Booster Set 2 Wave 3 (ORANGE)](https://web.archive.org/web/20001102114523/http://www.upperdeck.com/digimon/00entdbst2w3.html)

 The orange and yellow releases of Booster Set 2 actually listed on the case which holo cards were available in the set but I haven't seen a case for Booster Set 1 which shows this information. Thanks to a certified legend I met online I have a list of what we believe to be all the chase cards released.

There are 6 chase cards in each set that we know for certain and 12 cards that are currently unknown, so my guess is there was another couple of waves for Booster Set 1 or 2 that included these cards. That's just guessing though.

**24/04/2021 UPDATE:**
Thanks to YouTube comments pointing me to a Digimon Booster pack opening [video by CyberKnight](https://www.youtube.com/watch?v=pdzm4otLvq8), I've got more info. In this video CyberKnight opens a Green Booster Set 1 pack which contains ST-46S Mammothmon. Given that the holos are released in batches of 6 I think we can assume that ST-45S to ST-57S were also released in this pack. Furthermore, because these card numbers start immediately after ST-44S (the last card in the known Booster Set 1 holos) I think we can assume that the Green Packs are Booster Set 1 Wave 2 and the set that was officially documented on UpperDeck's website is Booster Set 1 Wave 1.
