Discover Vintage Digimon Card Collecting

Digi-Battle is the original Digimon Trading Card Game (TCG) released in the West. This website is an open-source, community project to archive and document this card game from 1999.

Digi-Battle.com is your one-stop destination for everything Digi-Battle!

Not sure where to start? Why not check out the card set list.

A Community Project

This site is open-source and supported by user contributions. If you want to make the site better by writing an article, updating card info or implementing new features then check out the GitHub!
