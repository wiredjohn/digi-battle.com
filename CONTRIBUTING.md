# Contributing

Firstly, thank you for wanting to contribute! Any and all help is appreciated even if you just want to leave feedback.

There are several ways to contribute:

- Write or improve an article 
- Submit a DW-01 MetalGreymon card
- Correct card information
- Improve the website/code
- Report an issue
- Ask a question or get in touch

Contributions can be submitted through GitHub pull requests or issues.

There are issue templates for:

- [Writing an article](https://github.com/wiredjohn/digi-battle.com/issues/new?template=article.yml)
- [Submitting your DW-01 MetalGreymon card](https://github.com/wiredjohn/digi-battle.com/issues/new?template=dw01.yml)
- [Reporting a generic issue](https://github.com/wiredjohn/digi-battle.com/issues/new)

If you're submitting a code change, the following process will be followed:

1. Fork the repository
2. Create a branch
3. Make your changes
4. Open a pull request
5. A maintainer reviews the contribution
6. Once approved, it is merged and deployed

You can also use the [Discussions tab](https://github.com/wiredjohn/digi-battle.com/discussions) to leave feedback or ask a question.
