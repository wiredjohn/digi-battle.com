Most of the text on this card is using the wrong font and looks super weird. Additionally the text in the special effect box is so big it spills outside of the box. This issue was fixed with the Cereal Promo release of [Numemon (CP-35)](/upper-deck/cards/numemon-cp-35). It was also corrected in a later printing of BO-63, but the misprint is much more common than the corrected version.
