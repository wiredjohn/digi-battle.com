**SITE REBUILD!**

Digi-Battle.com has been completely rebuilt. The old ASP.NET + Bootstrap site has been replaced with a static Jekyll site.

This was a major project with a few key goals in mind:
- Improve the user experience
- Make it easier to update and add new content
- Open-source the project

The site is now more responsive, easier to navigate and generally nicer to use. The cumbersome .NET stack and MSSQL database have been replaced with YAML data files and Markdown, so adding new pages or updating card data is a simple text change instead of a manual redeployment. And now anyone can contribute to the site on [GitHub]({{site.data.external_links.gh_home}}).

In the redesign and removal of the back-end, some features have been lost:
- Contact Form (replaced by [GitHub repo]({{site.data.external_links.gh_general_contact}}))
- Page hit analytics
- Card Compare Page (will be recreated soon!)
- Original language text for French cards
- "Ranks" on card pages (data is [still available in this article](/articles/strongest-digimon-cards))

Almost every aspect of the site has been improved and it's now in a much better position to continue growing.

Please feel free to leave feedback via [GitHub]({{site.data.external_links.gh_general_contact}}).

Thank you for using Digi-Battle.com. There's more cool stuff to come!
